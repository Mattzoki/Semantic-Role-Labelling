# Assignment 1: Logistic Regression for Text Classification

This project involves preprocessing CoNLL-U files, feature extraction, and training a logistic regression model for classification using `scikit-learn`. The assignment makes use of SpaCy for NLP preprocessing and visualizes performance with confusion matrices and classification reports.


- `Assignment1.ipynb`: Main notebook with all code for preprocessing, training, and evaluation.
- CoNLL-U input and output handling via file conversion functions.
- Logistic Regression used for classification.
- Visualizations of evaluation metrics using Matplotlib.


Install the required Python libraries with:

pip install -r requirements.txt
